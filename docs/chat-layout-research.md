# 有码 · 聊天截图的识别（2026-10-14）

## 要做什么

认出一张图是聊天记录截图，自动遮住每个发言者的**头像**、**昵称**，以及顶栏的**聊天标题**（对方名字或群名）。

## 为什么不用模型

| 方案 | 结论 |
|---|---|
| 版面规则 + 像素 | **采用**。不加包体、不加依赖，每条命中都能解释，和文字规则一个路子 |
| 小型目标检测（PP-PicoDet、YOLOX 之类，1–8 MB） | 留作后手：规则在真实截图上漏得多时再上。要数据和训练流水线；Ultralytics YOLO 是 AGPL，和内购版冲突，不能用 |
| 只判断「是不是聊天截图」的分类器 | 不需要：规则本身就给出这个判断 |
| 多模态大模型 | 不随包大模型（见 [on-device-model-research.md](on-device-model-research.md)）；Gemini Nano 只有少数机型有，小模型给的框也不准 |

## 各家的版面

各家聊天软件只有两种版式，共用四个部件：顶栏标题、贴边的一列头像、昵称、底部输入栏。

**左右气泡式**（绝大多数）：别人的消息靠左、自己的靠右；别人的头像在最左边一列。

| 应用 | 头像 | 自己的头像 | 群聊昵称 | 单聊有昵称 |
|---|---|---|---|---|
| 微信、企业微信 | 左，圆角方，顶对齐，每条都画 | 右 | 气泡上方小字（企业微信带「@公司」） | 无 |
| QQ | 左，圆，顶对齐 | 右 | 气泡上方，前面可能有等级、头衔标签 | 无 |
| 钉钉、飞书、抖音、小红书、微博、淘宝客服 | 左，顶对齐 | 右（飞书待核实） | 气泡上方 | 无（客服有） |
| LINE、KakaoTalk | 左，顶对齐 | 无 | 气泡上方 | 有 |
| WhatsApp | 群聊才有，左，顶对齐，一组一个 | 无 | 气泡里第一行，彩色 | 无 |
| Telegram、Signal | 群聊才有，左，底对齐，一组一个 | 无 | 气泡里第一行，彩色 | 无 |
| iMessage、Messenger、Instagram、Google Messages | 左，底对齐，较小 | 无 | 气泡上方灰色小字 | 无 |

海外应用的单聊正文里一般没有头像，只在顶栏里有一个对方的头像（WhatsApp、Telegram、Messenger 在标题左边，iMessage 在标题上面）。

**单列列表式**（Discord、Slack）：消息都靠左、没有气泡；每组第一条左边一个头像，右边一行「名字 + 时间」。

## 规则（`app/src/main/java/moe/flinty/yomark/chat/ChatLayout.kt`）

所有长度按图宽量：长截图的高可以是宽的五六倍。

1. **分区**：状态栏（屏宽 8.5% 以上）不看；状态栏以下第一行字是标题，紧跟的状态行（「最近在线」「23 位成员」「last seen」）也算顶栏；底部屏宽 17% 是底栏。
2. **是不是聊天页**，几样特征各记几分，到 5 分才算：
   - 底栏里有输入栏的字（「发送」「Message」「iMessage」「Aa」……）+3；底栏是「微信 通讯录 发现 我」这样的导航栏 −4；
   - 居中的时间 +1 / +2；居中的系统消息（撤回、加入群聊、joined）+1；
   - 左右两列消息 +2：靠右一列要右缘对齐、左缘参差（右缘、左缘都对齐的是商品列表的第二栏）；
   - 「名字 + 时间」的消息头 +2；
   - 一列头像 +2，左右两列头像 +3；
   - 行尾一列时间（会话列表每行右上角的「10:24」「昨天」）−3。
3. **头像**：左右各一条屏宽 20% 的沟，按 40 格一段取这一边屏幕最边上的颜色当底色（不在整条沟里取：纯色头像会占了大半；
   左右分开取：Telegram 的渐变壁纸斜着变色，左右两边不一样）。右边最外一道和往里一条的颜色不一样时（微信滑动时那道屏宽 1% 的灰滚动条），往里挪一点取；
   和底色差得多的像素里，从沟的外框一格格平缓过渡（相邻差不过 15，和底色差不过 90）走得到的是渐变壁纸，去掉（涂鸦的细线跨过去）；
   再开运算去掉壁纸涂鸦，闭运算、填洞，留下近正方形、填充率高、宽在屏宽 4.5%–13%、贴边（离边 6% 以内，另一边不过 15%：微信的头像到 12.9%）的块。
   真去掉了渐变的，不去再找一遍：本身渐变、一头和底色差不多的头像，去渐变时会被吃掉半边。
   被粗涂鸦和气泡连成一大块的，往里腐蚀三圈断开细的搭桥，各自长回去再看像不像头像。
   每块要有另一块大小相近、离边一样远的作伴（左右镜像也算）。头像列找到以后，在列里再找形状不规整的块（灰白默认头像只剩剪影），按列里头像的大小补框。
   顶栏里挨着标题（同一高度或就在它上面）的一块是顶栏头像。
4. **昵称**：
   - 靠左、短、有字母或汉字、不是句子和时间、不以冒号结尾，下面紧跟一行左缘对齐（微信气泡里的字缩进一点，往右放宽到屏宽 4.5%）、字更大（小于 0.88 倍，也小于这页消息字高的 0.95 倍：网址、邮箱那种全是字母的行框更高）的消息；
     或者下面是图片（截图上读出来的小字不到名字字高六成，不算消息）、但顶边和左边头像的顶边对齐；
   - 已经认出两个以上时，和它们左缘对齐、一样大小的小字也算；
   - 「名字 + 时间」的消息头（OCR 读成一行的，按字数比例切出名字那一截）；
   - 系统消息里的名字（「"张三" 撤回了一条消息」只框张三；OCR 在小字之间补的空格先去掉再配）；
   - 头像上印着字（默认头像上的姓）时，OCR 会把它和昵称读成一行「卢 曹雨」：压在头像上的字先切掉。
   - 彩色的昵称（Telegram、WhatsApp 的群聊，引用回复里被引用的人名）：字号和消息一样，比不出大小，按字的颜色认：靠左、像个名字、字是彩色的，下面一行（中间可以隔着引用里另一个彩色人名）是白字或黑字。彩色的网址、置顶消息条不算。
     一段开头的（气泡第一行的发送人、引用里的人名）放宽：名字后面跟着头衔、助力数（OCR 读成一行）的到 40 个字，带数字也算，整行都遮；
     消息中间的彩色字（链接、文档标题）不放宽。居中的也算（带缩略图的引用人名往右挪，可能正好落在正中）。
     彩色名字底下紧跟的那行小字是他说的话（引用回复里被引用的那句），不当昵称；
   - Telegram 转发的消息：彩色的「转发自」「Forwarded from」后面，或紧接着的下一行（也是彩色的），是原发送人、频道的名字；
   - 微信的引用：消息下面一块小字「方小禾：[图片]」，只遮冒号前的名字。字和消息一样大的「地址：……」、标签词（备注、电话……）、「今天 09:12」、网址不算。
5. **标题**：去掉人数「(23)」和 iMessage 的「›」，框按字数比例缩到名字那一截。

三类都归设置里「聊天记录」一项（打码 / 仅圈出 / 关闭），出厂打码。页面转了直角的不认。

## 实测

测试页由 `tools/model-eval/make_chat_samples.py` 生成（全是编的）：9 种皮肤（微信、QQ、Telegram、WhatsApp、iMessage、LINE、Messenger 各有浅色深色、单聊群聊，Discord 两张），
头像有纯色带字、渐变、拼色「照片」、风景、灰白默认头像，消息有文字、图片、语音、时间、系统消息，部分是 JPEG、720 宽、1170 宽和长截图；
另有 5 张不是聊天的页（通讯录、会话列表、设置、商品列表、文章）。OCR 行是生成时记下的，量的是版面规则本身。

挑进单测的 37 张（缩到 540 宽，`app/src/test/resources/chat/`）上调的规则；另外 28 张没参与调参，一起量（下表是 2026-10-14 拿真截图校之前量的，之后没重跑）：

| 65 张 | 认出 / 共 | 多出 |
|---|---|---|
| 头像 | 382 / 400（96%） | 2 |
| 昵称 | 214 / 221（97%） | 10 |
| 标题 | 60 / 60 | 0 |
| 聊天页判断 | 65 张全对 | |

漏掉的头像主要是和底色几乎一样、连剪影都很淡的那种。真 OCR 的端到端在 `ChatDetectorTest` 里跑（上架截图那张单聊页、缩到 540 宽的合成群聊页）。

2026-10-14 拿两张真截图校了一遍（真人真名，不进仓库），真 OCR 读：

| | 改之前 | 改之后 |
|---|---|---|
| Telegram 群聊（浅色、斜渐变涂鸦壁纸、引用回复、转发、头衔） | 头像 0/7；昵称认出 5/9，多出「转发自」和引用里的一句话 | 头像 7/7，昵称 9/9，不多 |
| 微信深色群聊（右边有滚动条、输入栏空着、图片消息、引用） | 不算聊天页（4 分），什么都没遮 | 头像 4/4，昵称 5/5（含两处引用），标题 |

合成页上头像、昵称、标题和改之前持平（37 张单测页：头像 214/219，多出的从 2 个降到 1 个）。

## 已知的不足

- 合成页由同一个脚本画出，和真实截图的字体、间距、图标有出入；真截图只校过 Telegram、微信各一张，别的应用还没有。
- 被裁掉顶栏和输入栏的截图，判断聊天页的分数会少一截，只剩气泡列和头像列。
- 电脑版、平板横屏（左边多一栏会话列表）不认。
- 气泡里的转账、名片里的名字和小头像不认；QQ 的引用回复不认。
- Messenger、Instagram 气泡下方的已读小头像不认；Telegram 回应（表情后面那几个小圆头像）也不认：和表情一样大，分不开。
