## 聊天截图
- 新增「聊天记录」：认出聊天截图后，遮住头像、昵称和顶部的联系人或群名，默认打码
- 微信、QQ、Telegram、WhatsApp、iMessage、LINE、Messenger、Discord、Slack 的版式都认得
- 截图按原分辨率识别，长截图分段识别，群聊里的小字昵称、彩色昵称不再漏掉

## 给别的应用选图
- 在别的应用里选图时可以选「有码」，打完码点「完成」直接交回去，例如 Telegram 的「在外部应用中打开」
- 交回去的图不存进相册

## 编辑页
- 手机上的底栏改成悬浮的一行：「打码」「编辑」点开就地展开工具，AI 检查和按住对比是旁边的圆按钮；「导出」挪到右上角
- 再点一下当前样式，调节面板从底栏长出来，盖在图上；点面板外面收起
- 画笔可以用了；马克笔和画笔都能拉框或手画
- 用途水印的设置也用同一种面板
- 换色块、马赛克、模糊时，图上已有的这三种码一起换，「应用到全部」去掉；在「设置 › 编辑」里可以关掉
- 识别出来直接打的码、点了打码的虚线框、导出前的「全部打码」都用「打码」里上次选的样式，拿着马克笔、画笔时也不会打成标记
- 以前动过画笔的安装，马赛克和模糊回到中档
