## 人名认得更准
- 不再把药名、品牌名、规格词当成人名：商品规格页上「福来恩」「海乐妙」「成猫」「单月」这类不会再被圈满
- 从字面猜出的人名要有旁证才算：名字紧跟「先生」「女士」「老师」这类称呼，或者同一行、上下相邻一行有电话、证件号、地址、「收货人」「乘车人」这类字段。有旁证的直接打码（以前只圈出）
- 没有旁证的人名（比如聊天里随口提到的）默认不再圈出。需要的话，在 设置 › 文字 › 人名 里打开「没有旁证的也圈出」，这些名字会圈出、不打码
- 认得出更多「姓 + 称呼」：张先生、刘老师、赵小姐……；「班主任」「向老师请教」「康师傅」这类不会被当成人名
