## 新增
- 购买弹窗支持兑换码，输入正确的兑换码即可去除水印
- 新增首页与两级设置页，各页面支持预测性返回
- 用途水印可调颜色、角度、透明度与密度，带实时预览；编辑器内可预览并显示是否开启
- 条码默认按严格模式识别；新增导出提醒开关
- 识别时页面变暗提示，全应用文案更直白

## 修复
- 页面内容不再被状态栏、导航栏遮挡，系统栏图标改为深色
- 类型标签可放在框的任意一侧，不再与其他框和标签重叠
- 丢弃无法解码、实为彩色照片的条码候选
- 无字段标签的人名识别并回统一的「人名」规则

## 安装包
debug 签名 APK：真机装 arm64-v8a，模拟器装 x86_64。
