## 新增
- 设置改版：首页只列分类（文字、人脸、条码、文字识别、导出、外观），每项带一个彩色图标，下面一行写着当前状态；具体选项都在点进去的页面里，样式参照 Android 16 的系统设置
- 人脸、条码也能设为「打码」「仅圈出」或「关闭」，和文字规则一样；原来的识别模式（快速 / 精确、严格 / 宽松）照旧可选
- 主题色默认跟随系统壁纸取色（Android 12 及以上），也可以在「设置 → 外观」里换成紫、蓝、青、绿、橙、红、粉
- 新的识别动效「磨砂」：整页模糊、闪着细碎的光点，识别完从中心散开；在「设置 → 外观」里与扫光切换

## 改进
- 文字规则每一类前面加了图标，关 / 圈出 / 打码改成一排按钮，各类的状态一眼就能看出来
- 「恢复默认设置」会先确认，主题色和识别动效不受影响
- 之前在设置里关掉过人脸或条码的，升级后仍然是关闭

## 安装包
固定签名 APK：真机装 arm64-v8a，模拟器装 x86_64。已经装了 v0.3.3 的可以直接覆盖升级。
