## 编辑页
- 顶栏新增「对比」按钮：按住看打码前的原图，松手回到打码后；还没打码时按钮是灰的
- 点样式栏上的一种样式只换样式，不再每次都弹出调节面板；要调颜色、表情、粗细，再点它一下。选中样式名字后的小箭头收着时朝上、开着时朝下
- 手机横着拿时，样式和导出挪到画布右边，画布不再被挤成窄窄一条；调节面板在右边那一栏里打开，不盖住图
- 二维码、条码打码时往外多盖几个像素，右边和下边不再露出一条

## 设置
- 连点版本号打开调试信息后，设置首页多出「开发者」一项，调试信息的开关、调试记录、保留几次都在里面
- 「恢复默认设置」挪进「关于」

## 购买（Google Play 版）
- 买完后购买框立即关闭，并弹出一页感谢；在编辑器里买的，回到首页也立刻是已购
- 重装后恢复的老购买悄悄生效，不会再谢一次

## 安装包
固定签名 APK：真机装 arm64-v8a，模拟器装 x86_64。
