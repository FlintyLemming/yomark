## 首次打开
- 引导多了欢迎页和「识别引擎」页：后台实测一次 PP-OCR，3 秒内用 PP-OCR，慢了自动换 ML Kit
- 中文以外的语言用英文示例截图
- 示例图固定不动，只有文字翻页；欢迎页图标换成慢慢转动的 Material 形状

## 打码
- 顶栏「导出」左边新增「分享」：打码后直接发到分享面板，不存相册；批量时一次分享全部
- 英文的 p、g、y 等下伸部分也能盖住
- 点手机底栏上的按钮有轻微振动

## 平板和折叠屏
- 编辑器的功能平铺成一组方块，面板从点到的方块里展开
- 设置左边是列表、右边是打开的页面
- 框列表里手动框只显示类型

## 设置
- 识别引擎只剩 PP-OCR 和 ML Kit 两项，移到「AI」页；原来选 ML Kit 英文 / 中文 / 中英的都归为 ML Kit

固定签名 APK：真机装 arm64-v8a，模拟器装 x86_64。
