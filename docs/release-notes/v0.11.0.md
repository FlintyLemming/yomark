## 平板和折叠屏
- 宽屏（平板、书本式折叠屏、Pura X 这类宽折叠屏）的编辑页换了布局：画布旁边多一张列表，列出图上每一块码，带原图截取、类型；模型猜出的标「AI」
- 点列表里的一行，和点画布上的框一样：打码 / 取消打码，或者选中手画的框。已打码的行变淡，还没定的行保持彩色、带琥珀色边框
- 六种打码样式变成填满空间的圆角方块。竖着拿时样式和列表在画布下面，横着拿时挪到右边一栏
- 平板转屏时画布的缩放和扫描动画不会被打断
- 手机的布局不变

## 编辑页
- 「AI 增强识别」按钮上的两颗星改成一前一后绕着转，前面那颗挡住后面那颗，每转半圈慢起慢停

## 安装包
固定签名 APK：真机装 arm64-v8a，模拟器装 x86_64。
