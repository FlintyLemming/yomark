## 首次打开
- 第一次打开是三页引导，在一张示例聊天截图上演示自动打码、点文字打码和识别聊天记录
- 设置里新增「帮助」，可以再看一遍引导

## 打码
- 点一下文字只打手指下的那一段，不再把同一行的按钮、缩略图一起盖住
- 新增「大爆炸」：长按文字逐字选，选中就打码，连着选的合成一块
- 底栏的 AI 圆钮变成「工具」，里面是 AI 增强识别和大爆炸；没有 AI 时直接是大爆炸
- 快递单号并入「长数字串」：8 位以上的数字（可带连字符和大写字母）都算
- 取件码默认打码，短信句子里的（「凭取件码36920471取件」「请凭8-5-2001于21:00前取件」）和单独一行的都认得出
- 识别动效默认「磨砂」

## 编辑
- 「编辑」新增「文本」：点图片写一行字，可以改字、移动、缩放，选颜色、字号和背景
- 画笔新增「箭头」
- 收起「编辑」后回到上次的打码样式，在收起的工具栏上点、拖都是打码
- 切换工具不再抖；返回收起分组改成弹簧动画
- 窄屏手机上顶栏的「导出」变成图标，不再折行
- 滑块的档位名不再折成两行

## 设置
- 合并成一个「通用」页，文案更短
- 新增「按原分辨率识别」，默认关闭：截图先缩小再识别，慢手机上更快
- 关于里新增「反馈」：发邮件或去 GitHub Issues，自动带上版本和设备

## 安装包
原生库改为压缩存放，arm64 安装包从 174 MB 降到 66 MB。

固定签名 APK：真机装 arm64-v8a，模拟器装 x86_64。
