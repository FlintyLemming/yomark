## ⚠️ 包名变了，会装成一个新应用
英文名从 Youma 改为 Yomark，中文名仍叫「有码」。包名随之改为 `com.yomark.app`，系统会把这个版本当成另一个应用：
**它不会覆盖已安装的旧版，装好后桌面上会有两个「有码」，请把旧的那个卸载掉**（在系统「设置 → 应用」里，版本号为 0.4.0 或更早的那个）。

- 设置不会带过来，需要重新设一遍；用兑换码去掉过水印的，在新版里再输一次兑换码
- 新导出的图片存在相册的 `Pictures/Yomark` 里；以前导出的图片还在原来的相册，卸载旧版不会删掉它们

以后的版本都可以在这一版上直接覆盖升级。

## 改进
- 画完的框直接处于选中状态，马上就能拖四个角调大小、拖中间挪位置，不用再长按
- 之后想再改，点一下手动框就能重新选中；手动框不再在打码和圈出之间切换，不需要的直接删掉
- 选中框、四角手柄和正在画的框改用主题色，白底截图上也看得清
- 「删除」改成框上方的一个小工具条，上方放不下时放到框下方
- 免费版的水印改为「有码 Yomark」

## 安装包
固定签名 APK：真机装 arm64-v8a，模拟器装 x86_64。
