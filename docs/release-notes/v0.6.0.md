## 每块码各用各的样式
- 样式栏选的是接下来打码用的样式：新画的框、点了打码的虚线框用新样式，已经打好的码不变
- 选中一块手动框时，样式栏显示它的样子，在面板上改它会跟着变；想让整张图统一，点面板上的「应用到全部」
- 点一种样式就在样式栏下方弹出调节面板，不用进设置页：
  - 色块：预设色、自定义颜色、吸管从原图取色
  - 表情：20 个表情、底色、单个或排满一行
  - 抹除：背景太复杂、改用色块时的颜色
  - 马赛克：颗粒粗细（只能比默认更粗）
  - 模糊：强度（只能比默认更强）
  - 马克笔：荧光色、自定义、吸管，浓淡 20%～70%
- 调好的样子会记住，下次打开沿用
- 混用样式时，预览和导出按同一个顺序绘制，导出结果和预览一致
