## 打码
- 去掉「只框出」：认出来的要么直接打码，要么不打；以前默认只框出的网址、IP、快递单号、长数字、日期时间改为默认关闭
- 不再画虚线框；点一下没打码的文字，整行打码，再点一下取消
- 点掉的识别结果（包括头像），在原处再点一下就回来
- 打码像贴胶带一样从左往右抹上，取消时从左往右揭开
- 导出前不再提醒，图上是什么样就导出什么样
- 设置里每一类只有「打码」「关闭」

## AI 检查
- 设置里开着的类别都会找，聊天昵称和群名也算；在 55 页测试集上找到的从 29% 提到 69%
- 找到的直接打码
- 按钮换成三颗星，检查时会转

## 实验室
- 设置首页新增「实验室」
- 聊天记录挪到这里，默认关闭
- 新增「外部模型」：AI 检查改用自己填的 OpenAI 兼容接口，只发识别出的文字，规则认出的号码先换成占位符
- 应用可以联网了；默认不联网，开了外部模型才会连

## 聊天截图
- Telegram：渐变壁纸上的头像、深色群聊、自己消息里引用的名字、被输入栏挡住的名字、转发来源都能遮
- 只有别人消息的微信群截图也认得出
- Telegram 自己发的消息里的时间，不再让截图被当成聊天列表

## 水印
- 打开水印面板不再直接盖上，打开「应用」才加
- 水印工具只在选中时高亮

## 画布
- 不再双击缩放，只用双指
- 模糊、马赛克只算一次，缩放、拖框更顺
- 识别时毛玻璃一开始就盖满整页，出结果前不再卡一下
- 工具栏和样式面板收起更快

## 安装包
固定签名 APK：真机装 arm64-v8a，模拟器装 x86_64。
