# 有码 · Google Play 商品详情

上架 Play 的是内购版（`-Pyomark.freeEdition=false`）：免费导出带「有码 Yomark」小水印，一次性买断去掉。
下面的文字和图片都按这个版本写、按这个版本拍。应用界面只有简体中文，商品详情的默认语言选「中文（简体）– zh-CN」。

## 文字

### 应用名称（11/30）

```text
有码 - 截图自动打码
```

备选：`有码：截图隐私自动打码`（11）、`有码 Yomark - 截图自动打码`（18）。名称里不放「免费」「最好」、表情符号这类 Play 不允许的词。

### 简短说明（45/80）

```text
截图发出去之前先打码：自动找出手机号、地址、人名、取件码、人脸和二维码，本机识别，不联网。
```

### 完整说明（1363/4000）

```text
截图里的手机号、地址、人名、取件码、人脸和二维码，有码会自动找出来并打上码。识别、编辑、导出全在手机上完成：应用没有联网权限，也不会向你申请相机、存储、位置、通讯录等任何权限。

【隐私】
• 没有联网权限：不是承诺「不上传」，而是系统层面就不给这个进程开网络，开着飞行模式也照常工作。
• 不申请运行时权限：选图走系统的照片选择器，应用只拿得到你选中的那几张，读不到相册里的其他图片。
• 安装包里只有几条不涉及读取数据的声明，例如 Google Play 结算库带进来的 BILLING，只用于应用内购买。
• 干净导出：按原图分辨率重新绘制、重新编码，位置、机型、拍摄时间等 EXIF 信息一律不保留。
• 没有账号，没有广告，不收集任何数据。

【怎么用】
1. 选一张图，或者在相册里把图分享给「有码」，一次可以分享多张。
2. 等一两秒识别完。天蓝色块是已经打码的，琥珀色虚线框是拿不准、等你确认的，点一下就能切换。漏掉的地方，用一根手指拖出一个框补上。
3. 点「导出」。还有圈出但没打码的内容，导出前会先列出来提醒你。

【识别范围】
默认直接打码：电话、邮箱、人名、地址、取件码、银行卡号、IBAN、护照号、社保号、密钥（API key）、MAC 地址、人脸、能解码的二维码和条形码。
默认只圈出、等你确认：快递单号、订单号等长数字串、日期时间、网址、IP 地址。
每一类都可以在设置里改成「打码」「仅圈出」或「关闭」。

文字由随应用安装的 PP-OCRv6 模型识别；哪些算敏感信息交给规则判断：正则加校验位（比如银行卡号的 Luhn 校验），每一处命中都说得出原因。人脸和条码由 Google ML Kit 的离线模型识别。模型都打包在安装包里，装好就能离线使用。

【六种打码样式】
色块、表情、抹除、马赛克、模糊、马克笔，每一块码可以用不同的样式。色块颜色、表情和底色、马赛克粗细、模糊强度、马克笔颜色和浓淡都能调，还能用吸管从图上取色。预览和导出用同一套渲染器，导出的就是你看到的。
提醒：截图的字体固定、背景干净，马赛克和模糊有可能被还原。需要真正隐藏信息时，请用色块、表情或抹除。

【更多功能】
• 手动补框：拖出的框可以拖四个角调大小、拖中间挪位置；双指缩放和平移图片。
• 批量处理：在相册里一次分享多张，逐张看过后一起导出。
• 用途水印：在整张图上平铺一行字，例如「仅供办理签证使用」，被挪作他用时一眼就能认出来。颜色、角度、透明度、密度都能调。
• AI 复查：在支持的机型上（如 Pixel 9 及以后），可以让手机本机的 Gemini Nano 把整页文字再读一遍，新发现的内容只圈出、不自动打码。
• 主题色默认跟随系统壁纸（Android 12 及以上），也可以换成紫、蓝、青、绿、橙、红、粉中的一种。

【关于付费】
下载免费，全部功能都能用，隐私保护能力一项不缺。免费导出的图片右下角会带一个「有码 Yomark」小水印，自动避开打码区域；一次性买断即可去掉，永久有效，不是订阅。这是唯一的付费项。

【开源】
源代码、设计文档和测试记录都公开在 GitHub：github.com/FlintyLemming/yomark

支持 Android 10 及以上版本。
```

## 写法上的约束

- **首屏写明权限**（[上架验收记录](../release-checklist.md)「上架前检查」）：开头一段就说没有联网权限、不申请运行时权限；「隐私」一节说明 BILLING 来自 Play 结算库、不涉及数据访问。
- **付费只去水印**：「关于付费」一节照付费对话框的说法——一次性买断、不是订阅、隐私能力一项不缺。
- **马赛克和模糊不写成安全手段**：样式一节专门提醒它们可能被还原，要真正隐藏请用色块、表情或抹除。
- **不提打赏**：Play 的付款政策不允许在商品详情里把用户引到 Play 结算以外的付款方式。开源一节只放 GitHub 仓库地址。
- **图片里不写「免费」「最好」「第一」**，置顶大图不重复画应用图标，截图不套手机外框——都是 Play 素材指南里明确不建议的。

## 重新生成

截图拍的是真实应用：`PlayScreenshots` 在 Robolectric 上跑随包的 PP-OCR 模型、出厂规则和真的编辑器，配上标题后再渲染成成品。
界面或识别结果变了，按顺序重跑：

```sh
# 1. 拍编辑器截图（中间产物，不进仓库）
YOMARK_PLAY_SHOTS_DIR=$PWD/docs/play/shots ./gradlew -Pyomark.freeEdition=false \
    :app:testDebugUnitTest --tests '*PlayScreenshots*'

# 2. 渲染图标、置顶大图和 8 张截图（需要 Playwright 和能访问 Google Fonts 的网络）
NODE_PATH="$(npm root -g)" node docs/play/src/render.cjs all

# 3. 转成 Play 要的色彩模式，核对尺寸与体积
python3 docs/play/src/finalize.py
```

截图的标题、副标题和替代文字在 [`src/screenshots.json`](src/screenshots.json)；聊天记录样图的源文件是 [`src/chat-page.html`](src/chat-page.html)
（`render.cjs chat-page` 渲染到 `app/src/test/resources/play/chat-page.png`），快递详情样图沿用 README 的 `order-page.png`。样图里的人名、地址、号码都是编的。
