# 有码 · 宽屏适配（平板、折叠屏、阔折叠）

对 `2026-09-02-yomark-android-design.md` §7（编辑器交互规格）的增补。

## 起因

平板上编辑器照搬手机的排法：画布在上，一排样式和导出在下，宽出来的地方全空着。用户的要求：

1. 宽屏多一种选择方式：画面上框出来的内容以列表形式列在一侧，点列表里的一项，同样是打码 / 取消打码；
2. 版式照草图：画布在上；下面左边是两行三列的样式圆钮，右边是一列框出项的缩略图；
3. 横着拿时，下面这一块挪到画布右边，上下排；
4. 阔折叠能准确认出来的话也用这一套，普通手机不用。

## 哪些屏幕用宽屏版式

判断在 `EditorLayouts.choose`，只看 Configuration 里的窗口尺寸，不认机型：

| 条件 | 版式 |
|---|---|
| 最短边 ≥ 600 dp | 宽屏：平板、书本式折叠屏展开、三星 Fold8 Wide 这类 4:3 的宽折叠 |
| 最短边 500～600 dp，且长边不到短边的 1.8 倍 | 宽屏：阔折叠 |
| 其余 | 手机，横过来也一样 |

宽屏里竖着拿（宽 ≤ 高）是 `WIDE_BOTTOM`，横着拿是 `WIDE_SIDE`。

- **最短边**取 `smallestScreenWidthDp`，不随转向变：平板转个方向不会从宽屏变回手机，只是列表换个位置。
  分屏、自由窗口里它是这个窗口的，平板上分到三分之一的窗口和手机一样窄，用手机版式；
- **阔折叠**：华为 Pura X 的内屏 6.3 英寸、16:10、2120×1320，按常见的密度折算最短边约 500～530 dp。
  普通手机竖着拿四百出头；把显示大小调到最小，大屏手机能到四百八九十，老款 18:9 的到五百出头，
  但它们的长宽比都在 2 左右，1.8 这条线把它们挡在外面；
- 不用 Jetpack WindowManager 的铰链信息：翻盖折叠屏展开也报铰链，可它展开后就是一台普通手机；
  宽折叠又不一定报（华为在鸿蒙上跑安卓应用时不报）。看窗口的形状，管用的正是「这块屏幕放不放得下」；
- Configuration 的宽高从 Android 15 起含系统栏、之前不含，两种数值 `EditorLayoutTest` 里都列了。

## 版式

**竖着拿（WIDE_BOTTOM）**：画布在上，下面一块左边是样式圆钮、右边是框列表，导出那一行横在最底下，
和手机底栏的导出一个位置。这一块占画布能用的高度的 34%，夹在 260～380 dp。

**横着拿（WIDE_SIDE）**：画布在左，右边一栏从上到下是样式圆钮、框列表、导出那一行。
这一栏占宽度的 30%，夹在 320～400 dp：320 放得下用途水印面板顶上那一排按钮，再宽列表也只是空着。

**手机**：不变。

画布和旁边那一块由同一个布局摆（`CanvasAndPanel`），画布永远是它的第一个孩子。平板转个方向，
那一块从下面挪到右边，画布还是原来那一个：放大到哪儿、识别动效走到哪儿都接着来。
分开写成 Column 和 Row 的话，一转就是一块新画布。

## 框列表

- **列什么**：画面上的每一处框，识别出来的（打了码的、只圈出的）和手动画的都列。
  识别中（含换方案重跑）、换图载入中只列手动框：识别出的块这时在画布上也不画，点了也会被新结果整批换掉；
- **顺序**：从上到下、从左到右，和读这一页一样（`MaskListOrder`）。「同一行」要两块互相盖得住对方的竖直中点：
  人名和后面的电话一定算一行；左边一张大头像，只和中点挨着它中点的那一行字算一行，其余的字照样一行一行往下排。
  只看位置，打码、取消打码都不改顺序，点过的那一行不会跳走；
- **每一行**：原图上这一块的缩略图、类型名（和画布上的小标签同一套，Gemini Nano 的结果标「AI」）、状态。
  识别出的那几行右边一个开关，只圈出的描一道琥珀色的边，和画布上的虚线框同色；
- **缩略图**截的是原图，打了码的也是：在这儿就看得见码底下原来是什么，不用先取消打码再看——
  这正是 10-01 那一轮反馈想要的（见 `2026-10-01-yomark-editor-feedback-design.md`）。
  截外接矩形，四周留短边的四分之一，最大 720×240 像素；手动框整个拖出了图外就只留底色；
- **点一行**和在画布上点那一块一样（`EditorViewModel.onListItemClick`）：识别出的切换打码，进撤销栈，
  手动框的选中态收起；手动框那一行是选中它，不切换（spec §7.3），选中后照常在图上拖、在样式面板上改、点「删除」。
  吸管正等着取色时点了列表，先收起吸管，这一下照常算数；
- **顶上一行**：「框出 N 处」，有没打码的就带一个琥珀色圆点和「M 处未打码」——导出前会被提醒的就是这几处（spec §7.4）；
- 选中了手动框（刚画完的也是选中的）而那一行不在眼前，列表滚过去，看得见它进了列表。

## 样式圆钮

六种样式排成两行三列（`StyleGrid`），照草图一列一列地放：第一列色块、表情，往右是抹除、马赛克，再往右是模糊、马克笔——
左边盖得严，越往右越只是做个样子。和手机的样式栏是同一份状态、同一套动作：点一种换样式并弹出调节面板，
再点当前那一种收起或弹出面板；选中的那一个名字后面有小箭头；模糊、马赛克、马克笔的安全性说明贴在圆钮下面。

## 调节面板、用途水印

- **样式的调节面板**弹出来时占列表的位置，收起后列表回来。竖着拿时面板比列表那一块高，这一块就往上长，
  最多长到画布能用的高度的 48%（340～520 dp），再高面板里面滚动；面板短（马赛克、模糊只有一根滑条）就不动。
  长高、缩回去都是一点点来的，缩回去从展开时实际的高度开始，导出那一行始终贴着底边；
- **用途水印面板**竖着拿时和手机一样顶替下面那一块；横着拿时顶替右边那一栏，宽度不变，切过去画布不跳。
  输入法弹起时整块（画布和右边那一栏）让到键盘上面，打字时看得到整张图上的水印；
- 返回键的顺序不变：先收吸管，再收面板。

## 实现

- `EditorLayouts`：版式判断，纯函数；
- `EditorScreen` 里的 `CanvasAndPanel`：画布和旁边那一块；
- `WideEditorPanel`：宽屏的那一块，竖着拿和横着拿两种排法，以及两种尺寸规则；
- `StyleGrid`：样式圆钮，小样子沿用手机样式栏的 `StyleGlyph`；
- `MaskItemList`：框列表，连同 `MaskListOrder`（顺序）、`ItemThumbnails`（缩略图）；
- `EditorActionRow`：AI 复查、批量进度、导出 / 下一张，从手机底栏里拆出来，两边共用；
- 测试：`EditorLayoutTest`（各类设备的尺寸）、`MaskItemListTest`（顺序、缩略图、列表）、
  `EditorScreenLayoutTest`（手机、平板、阔折叠上出不出列表、列表在哪、点一行改不改 plan、面板占不占列表的位置）、
  `EditorViewModelTest`（点列表的四种情况）。

## 未验证

- 没上真机：只在 Robolectric 上按 800×1280、1280×800、528×848、848×528 dp 拍过截图看排版；
- 阔折叠的门槛是照 Pura X 的屏幕参数推的。Pura X 跑的是鸿蒙，安卓应用要靠兼容层，那里报给应用的密度和尺寸没见过；
  安卓上的宽折叠（三星 Fold8 Wide 内屏 7.6 英寸、4:3）最短边在 600 dp 以上，走的是平板那一条；
- 折叠、展开时 Activity 会重建（`configChanges` 只接了转向和尺寸），编辑状态靠 ViewModel 留着，没在真机上走过一遍；
- 竖着拿的阔折叠宽度只有 500 dp 出头，样式面板挤在圆钮右边，色板折成三行；
- 缩略图截自分析图（长边 2048），小字放大到 44 dp 高时会糊一点。
