# 有码 · 宽屏适配（平板、折叠屏、阔折叠）

对 `2026-09-02-yomark-android-design.md` §7（编辑器交互规格）的增补。

## 起因

平板上编辑器照搬手机的排法：画布在上，一排样式和导出在下，宽出来的地方全空着。用户的要求：

1. 宽屏多一种选择方式：画面上框出来的内容以列表形式列在一侧，点列表里的一项，同样是打码 / 取消打码；
2. 版式照草图：画布在上；下面左边是两行三列的样式按钮（草图上画成圆），右边是一列框出项的缩略图；
3. 横着拿时，下面这一块挪到画布右边，上下排；
4. 阔折叠能准确认出来的话也用这一套，普通手机不用。

## 哪些屏幕用宽屏版式

判断在 `EditorLayouts.choose`，只看 Configuration 里的窗口尺寸，不认机型：

| 条件 | 版式 |
|---|---|
| 最短边 ≥ 600 dp | 宽屏：平板、书本式折叠屏展开、三星 Fold8 Wide 这类 4:3 的宽折叠 |
| 最短边 500～600 dp，且长边不到短边的 1.8 倍 | 宽屏：阔折叠 |
| 其余 | 手机 |

宽屏里竖着拿（宽 ≤ 高）是 `WIDE_BOTTOM`，横着拿是 `WIDE_SIDE`。手机竖着拿是 `PHONE`；
宽比高多出 25% 以上算横着拿，是 `PHONE_SIDE`（见下面「手机横着拿」）。

- **最短边**取 `smallestScreenWidthDp`，不随转向变：平板转个方向不会从宽屏变回手机，只是列表换个位置。
  分屏、自由窗口里它是这个窗口的，平板上分到三分之一的窗口和手机一样窄，用手机版式；
- **阔折叠**：华为 Pura X 的内屏 6.3 英寸、16:10、2120×1320，按常见的密度折算最短边约 500～530 dp。
  普通手机竖着拿四百出头；把显示大小调到最小，大屏手机能到四百八九十，老款 18:9 的到五百出头，
  但它们的长宽比都在 2 左右，1.8 这条线把它们挡在外面；
- 不用 Jetpack WindowManager 的铰链信息：翻盖折叠屏展开也报铰链，可它展开后就是一台普通手机；
  宽折叠又不一定报（华为在鸿蒙上跑安卓应用时不报）。看窗口的形状，管用的正是「这块屏幕放不放得下」；
- Configuration 的宽高从 Android 15 起含系统栏、之前不含，两种数值 `EditorLayoutTest` 里都列了。

## 版式

> 2026-10-16 起导出在顶栏右上角，下面没有导出那一行了；方块里是所有功能，不只样式，见「所有功能平铺成方块」。

**竖着拿（WIDE_BOTTOM）**：画布在上，下面一块左半边是样式方块、右半边是框列表，导出那一行横在最底下，
和手机底栏的导出一个位置。这一块占画布能用的高度的 34%，夹在 260～380 dp。

**横着拿（WIDE_SIDE）**：画布在左，右边一栏从上到下是样式方块、框列表、导出那一行。
这一栏占宽度的 30%，夹在 320～400 dp：320 放得下用途水印面板顶上那一排按钮，再宽列表也只是空着。

**手机**：竖着拿不变；横着拿见下面「手机横着拿」。

画布和旁边那一块由同一个布局摆（`CanvasAndPanel`），画布永远是它的第一个孩子。平板转个方向，
那一块从下面挪到右边，画布还是原来那一个：放大到哪儿、识别动效走到哪儿都接着来。
分开写成 Column 和 Row 的话，一转就是一块新画布。

## 框列表

- **列什么**：画面上的每一处框，识别出来的（打了码的、只圈出的）和手动画的都列。
  识别中（含换方案重跑）、换图载入中只列手动框：识别出的块这时在画布上也不画，点了也会被新结果整批换掉；
- **顺序**：从上到下、从左到右，和读这一页一样（`MaskListOrder`）。「同一行」要两块互相盖得住对方的竖直中点：
  人名和后面的电话一定算一行；左边一张大头像，只和中点挨着它中点的那一行字算一行，其余的字照样一行一行往下排。
  只看位置，打码、取消打码都不改顺序，点过的那一行不会跳走；
- **每一行**：原图上这一块的缩略图、类型名（和画布上的小标签同一套，Gemini Nano 的结果标「AI」）、状态。
  不另放开关，打没打码看这一行的样子：打了码的整行灰下去（缩略图褪成灰、淡到 45%，底色退到和面板差不多），
  这一处已经处理好了；圈出没打码的保持彩色，描一道琥珀色的边（和画布上的虚线框同色），状态前一个琥珀色圆点，
  一眼看得出还剩哪几处要拿主意。切换时褪色、回彩有个过渡。读屏照样把整行当开关报（开 = 已打码）。
  起初右边放过一个开关，用户反馈多余：点整行就切换了，开关只占地方；
- **缩略图**截的是原图，打了码的也是：在这儿就看得见码底下原来是什么，不用先取消打码再看——
  这正是 10-01 那一轮反馈想要的（见 `2026-10-01-yomark-editor-feedback-design.md`）。
  截外接矩形，四周留短边的四分之一，最大 720×240 像素；手动框整个拖出了图外就只留底色；
- **点一行**和在画布上点那一块一样（`EditorViewModel.onListItemClick`）：识别出的切换打码，进撤销栈，
  手动框的选中态收起；手动框那一行是选中它，不切换（spec §7.3），选中后照常在图上拖、在样式面板上改、点「删除」。
  吸管正等着取色时点了列表，先收起吸管，这一下照常算数；
- **顶上一行**：「框出 N 处」，有没打码的就带一个琥珀色圆点和「M 处未打码」——导出前会被提醒的就是这几处（spec §7.4）；
- 选中了手动框（刚画完的也是选中的）而那一行不在眼前，列表滚过去，看得见它进了列表。

## 样式方块

> 2026-10-16 起方块里是所有功能，不只样式，面板从方块长出来，导出挪到顶栏，见下面「所有功能平铺成方块」。
> 方块的大小、圆角、放大的规矩照旧。

六种样式排成两行三列（`StyleGrid`），照草图一列一列地放：第一列色块、表情，往右是抹除、马赛克，再往右是模糊、马克笔——
左边盖得严，越往右越只是做个样子。和手机的样式栏是同一份状态、同一套动作：点一种换样式，
再点当前那一种才弹出或收起调节面板；选中的那一个名字后面有小箭头（收着朝上、开着朝下）；模糊、马赛克、马克笔的安全性说明贴在方块下面。

方块跟着给它的地方变大变小，是圆角矩形，不是固定大小的圆钮——第一版是 64 dp 的圆，平板上下面那一块的左边空出一大片：

- 竖着拿：铺满下面那一块的左半边（列表占右半边），高长到这一块的底，但不比宽高出 1.25 倍；
  调节面板开着、这一块跟着面板长高时，方块停在面板打开前的高度，不跟着拉长；
- 横着拿：铺满右边那一栏的宽，高取宽的四分之三，夹在 64～96 dp；
- 圆角取短边的 30%，最多 24 dp；短边大了，里面的小样子跟着放大（最多 1.6 倍），名字换大一号的字。

## 调节面板、用途水印

> 2026-10-16 起面板从点的那一块方块长出来，用途水印也在方块里，导出那一行没有了，见「所有功能平铺成方块」。

- **样式的调节面板**弹出来时占列表的位置，收起后列表回来。竖着拿时面板比列表那一块高，这一块就往上长，
  最多长到画布能用的高度的 48%（340～520 dp），再高面板里面滚动；面板短（马赛克、模糊只有一根滑条）就不动。
  长高、缩回去都是一点点来的，缩回去从展开时实际的高度开始，导出那一行始终贴着底边；
- **用途水印面板**竖着拿时和手机一样顶替下面那一块；横着拿时顶替右边那一栏，宽度不变，切过去画布不跳。
  输入法弹起时整块（画布和右边那一栏）让到键盘上面，打字时看得到整张图上的水印；
- 返回键的顺序不变：先收吸管，再收面板。

## 手机横着拿（2026-10-11 增补）

> 2026-10-16 起这一栏里是所有功能的方块，导出在顶栏上，面板从点的那一块长出来、盖满这一栏，见「所有功能平铺成方块」。
> 方块放不下时不再滚动：压扁到 48 dp，还放不下就四个一行。

起初手机横过来也照竖着的排：画布在上，一排样式、说明和导出在下。横着的手机只有三百多 dp 高，顶栏和底栏一占，
画布只剩一百来 dp 的一条。用户的要求：和平板一样把样式和导出挪到右边，但不要列表。

- **什么时候算**：不是宽屏，且宽比高多出 25% 以上（`PHONE_SIDE_MIN_ASPECT`）。横过来的手机宽是高的两倍上下；
  横屏分屏分到一半、小外屏这类近乎方的窗口，右边那一栏（至少 320 dp）一占，画布只剩窄窄一条，样式还是放在下面；
- **排法**：和宽屏横着拿一样宽、一样排，只是没有列表：样式方块在上，导出那一行在最底下，中间空着。
  方块的大小也照横着拿的规矩（高取宽的四分之三，320 dp 宽的一栏是 68 dp），不去撑满：
  切到模糊、马赛克、马克笔，说明一出来，撑满的方块就要矮一截，来回切换时一跳一跳的。
  字号调大的矮手机上放不下时，方块和说明在自己那一块里滚动，不压到导出那一行上；
- **样式的调节面板**：这一栏矮，方块底下放不下面板。弹出来时顶替方块，顶上写出样式的名字，方块下面的说明再说一遍
  （和竖着拿时弹出的面板一样），导出那一行还在底下；收起后方块回来。
  不用竖着拿时那种从底下弹出的面板：横着的屏幕上它几乎铺满整屏、盖住画布。放在这一栏里，画布照样看得见，
  选中的框跟着面板变也看得见，吸管取色时面板不用让开；
- **用途水印面板**和宽屏横着拿一样，顶替右边那一栏；
- 转个方向，画布还是原来那一个（`CanvasAndPanel`）。样式面板开着时转过来，竖着是弹出的面板，横着是这一栏里的面板。

## 所有功能平铺成方块（2026-10-16 增补）

用户的要求：宽屏、横屏的逻辑和手机基本一致。对比、AI 增强识别放进功能区，导出放到上面去，底下那一行就没有东西了；
和手机不一样的是所有功能都平铺着，不折叠。功能区的按钮和手机一个样子，一样的细边、投影；点开功能时有和手机一样的展开、收回动画，
只是菜单从那一个功能的圆角矩形长出来，不是手机上共用的那一条胶囊。中间试过一版折叠成「打码」「编辑」几组的，用户说不要折叠，撤了。

- **顶栏**：和手机一样，导出在右上角（别的应用来要图时是「完成」）；用途水印、对比不在顶栏上了。
  原先方块那一块最底下的「AI 增强识别」「导出」那一行没有了，批量时那儿只剩胶片条；
- **方块**：手机底栏里的功能都在，平铺着，三个一行：色块、马赛克、模糊，马克笔、画笔、文本，水印、AI 增强识别（用得了 AI 时）、大爆炸，
  按住对比。按手机上几组的先后排，用不了 AI 时正好三行。大小、圆角、放大照「样式方块」那一节的规矩。
  每一块的底子和手机底栏的圆钮一样（`floatingSurface`）；选中的那一块垫一层主题色、小样子和名字着主题色、名字加粗，
  和手机上展开后选中的那一项一样，换选中的也是那 250 ms。水印设了念「已开启」；AI 的结果写在它那一块上（跑着、跑完点不动、不灰），
  名字长的折成两行；对比按住才算，点一下弹提示说要按住；大爆炸没识别完、没认出字时灰掉；
- **面板从那一块长出来**：样式（再点当前那一种）、水印、大爆炸的面板从点的那一块圆角矩形长出来，收起时缩回那一块，
  和手机面板同一套动画：左右走 `foldSpec`、上下走 `panelFoldSpec`（收回去上下先落回来，角走一道弧），面板上的东西走 `contentFoldSpec`。
  - 样式、水印的面板落在列表的位置：从那一块底下钻出来（那一块画在它上面），走过别的方块时从它们上面盖过去，
    落定后不碰方块，开着面板也能换样式；手机横着拿没有列表，落满整一栏，盖住方块；
  - 大爆炸的面板落满整块，方块和列表都盖住：选字要地方，开着时也不该去点别的功能；
  - 盖住方块的那几种从方块上面长出来，那一块上的小样子和名字原地淡掉；
  - 面板落到的那一块（列表或方块）跟着淡掉，开着时点不着、读屏读不到；大爆炸开着时点列表也不算数（`onListItemClick`）；
  - 竖着拿时面板比这一块高，这一块一点点长高、画布跟着变矮，最多到 `OPEN_*`，方块停在原来的高度；
  - 图在旁边看得见，所以和手机不一样：点面板外面不收起，吸管取色时不缩回去，打字时不收成只剩输入框；
  - 盖住方块的面板盖满它盖住的那一块（横着拿是整一栏，竖着拿是闲着时的整块），字少的大爆炸底下也不留一截空着；
  - 开着一个面板又要开另一个：停稳了、又落在同一个地方的（样式、水印两种都落在列表的位置，开着面板换样式）就地换；
    别的（换成大爆炸、长按图上的字，或者还在半路上）先缩回原来那一块，缩到底再从新的那一块长出来，不从半路上跳过去；
  马克笔、画笔、文本一直拿在手里，没有手机上收起「编辑」就放下那一步（平铺着，没有收起）。
- **AI 那一块**：用得了 AI 的设备上一直留着（`EditorUiState.aiOffered`，最近一次探测说能用），这张图还没识别完时灰着。
  原先跟着每张图的识别出现、消失，方块一会儿三行一会儿四行，大爆炸、对比在手指底下挪位置；
- **吸管等着取色时**大爆炸那一块灰着：面板不收、方块都点得着，可这时打不开大爆炸；
- **地方不够时**：方块一齐压扁，最矮 48 dp（点得中）。手机横着拿的一栏三个一行压到 48 dp 还放不下（矮的手机、批量、有 AI），
  就四个一行，方块不压到胶片条底下。横着拿有列表时列表那一截至少留 200 dp 给面板落脚，方块压一压留得出就压；
  压到 48 dp 也留不出（弹着输入法的平板、横着拿的阔折叠），方块照原样，样式、水印的面板也盖满整一栏。
  竖着拿的这一块闲着时至少放得下 48 dp 的方块（阔折叠竖着拿、批量、有 AI 时比三成多高一点），画布照样留至少 200 dp。

## 实现

> 2026-10-16 起 `StyleGrid`、`EditorActionRow`、宽屏的 `StylePanel`、`PurposePanel`、`BigBangPanel` 都没有了：
> 方块、面板从方块长出来都在 `WideEditorPanel` 里（`morphRect` 是面板眼下的位置），面板里的东西和手机共用
> （`StylePanelContent`、`PurposePanelContent`、`BigBangContent`）。测试见 `WideEditorPanelTest`。

- `EditorLayouts`：版式判断，纯函数；
- `EditorScreen` 里的 `CanvasAndPanel`：画布和旁边那一块；
- `WideEditorPanel`：宽屏的那一块，竖着拿和横着拿两种排法，以及两种尺寸规则；
  手机横着拿也用横着的排法，不传列表（`list` 为 null），调节面板是 `StylePanel(standalone = true)`；
- `StyleGrid`：样式方块，自己量方块的大小；小样子沿用手机样式栏的 `StyleGlyph`（多了一个放大倍数）；
- `MaskItemList`：框列表，连同 `MaskListOrder`（顺序）、`ItemThumbnails`（缩略图）；
- `EditorActionRow`：AI 增强识别、批量进度、导出 / 下一张，从手机底栏里拆出来，两边共用；
- 测试：`EditorLayoutTest`（各类设备的尺寸）、`MaskItemListTest`（顺序、缩略图、列表）、
  `EditorScreenLayoutTest`（手机、平板、阔折叠上出不出列表、列表在哪、点一行改不改 plan、面板占不占列表的位置，
  手机横着拿时样式和导出在不在右边、面板顶不顶替方块）、
  `EditorViewModelTest`（点列表的四种情况）。

## 未验证

- 所有功能平铺成方块（2026-10-16）：模拟器（Pixel 10 Pro，用 `wm size 1280x1920`、`wm density 240` 当成 853×1280 dp 的平板，
  竖着、横着各看过）和它自己横过来（手机横着拿）上看过方块、样式和水印面板、大爆炸，动画放慢十倍截过半路上的几帧；
  模拟器上用不了 AI，有 AI 那一块的四行排法、批量的胶片条只在 Robolectric 上看过；平板真机、阔折叠、分屏、英文界面没看过；
- 没上真机：只在 Robolectric 上按 800×1280、1280×800、600×960、528×848、848×528 dp 拍过截图看排版；
- 手机横着拿：Robolectric 上按 880×363、745×316 dp（Pixel 7、360 dp 宽的小屏手机横过来、减掉系统栏）拍过截图，
  方块、说明、调节面板、用途水印面板都放得下；模拟器（Pixel 7，API 36）横过来看过状态栏、挖孔、手势条让开后的排法，
