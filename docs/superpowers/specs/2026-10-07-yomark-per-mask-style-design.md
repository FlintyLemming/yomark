# 有码 · 逐块样式与样式面板

对 `2026-09-02-yomark-android-design.md` §7.5「样式是全局的」、§8 的修订。起因是一轮反馈：

1. 默认的色块没法快速换颜色；
2. 选了别的样式，整张图上已经打好的码会被全部换掉。应该是选了之后，**下一次打码**——新画一个框、点一个虚线框准备打码——才用新样式；
3. 不只是色块的颜色，别的样式能加的自定义也都加上；这些设置不放进设置页，选了样式直接在下方弹出编辑框。

## 每块码有自己的样式

```kotlin
data class MaskLook(val style: MaskStyle = MaskStyle.SOLID, val options: MaskOptions = MaskOptions())
data class MaskItem(/* …原有字段… */, val look: MaskLook = MaskLook())
data class MaskPlan(val items: List<MaskItem>)          // 去掉了全局的 style、options
```

编辑器手里有一支**画笔**（`EditorUiState.brush`），就是样式栏上选的样式和面板里调的参数。画笔只管之后的打码：

| 什么时候打码 | 用什么样子 |
|---|---|
| 新画一个手动框 | 画笔 |
| 点虚线框（圈出）打码 | 画笔，不是它上一次打码时的样子 |
| 识别出来直接打码的 | 结果到达那一刻的画笔：识别期间换了样式，打上的就是新样式 |
| 导出拦截里的「全部打码」 | 画笔（批量时每一张都是） |
| 已经打好的码 | 不变 |

圈出的项也带着一份 `look`，但不画；退回圈出时不动它，再打码时换成当时的画笔。

**选中手动框时**（刚画完的框就是选中的）：样式栏显示那个框的样子；在面板上改，框跟着变，画笔也换成改后的样子——画完接着调颜色是最顺手的用法，之后再画的也是这个颜色。只是选中、什么都没改，画笔不动，取消选中后样式栏回到画笔。这是 tldraw、Excalidraw 的做法：选中时面板显示选中对象的属性，改了才同时成为下一笔的默认。

识别出的候选不进选中态（点它切换打码），想换它的样式：点两下（退回圈出、再用画笔打上），或者用面板上的「应用到全部」。

**「应用到全部」**：把这张图上所有已打码的换成样式栏上的样子，一步撤销得回来。原来「一换全换」的效果就是这一下。圈出的不动，它们打码时自然用画笔。按钮上写着会改几处，没有可改的就灰掉。

**撤销**：画笔不是 plan 的一部分，不进撤销栈，撤销也不会把画笔改回去；改选中框的样式进撤销栈，拖滑条的一整段只记一步（与拖框的 `previewSelectedQuad` / `commitDrag` 同一个做法）。

§7.5 当初不做逐项样式的理由是「要先选中再改，把点一下取消这个最高频的操作变成两步」。现在不需要先选中：样式栏是画笔，换样式本身不碰任何已有的码，点一下打码 / 取消照旧是一步。

### 绘制顺序

导出是在同一张位图上一块接一块地画，抹除、马赛克、模糊要读底下的像素，先画上去的色块会被它们读进去；预览读的却是原图。样式统一时这无所谓，混着用就不行了：抹除的采样环碰到隔壁的天蓝色块，导出时颜色一杂就降级成色块，预览却不降级。

所以预览与导出共用一个顺序（`MaskOrder`）：先画读像素的三种（抹除、马赛克、模糊），再画直接上色的三种（色块、表情、马克笔）；同一组里面积大的先画、小的盖在上面，与 `GestureRules.hitTest` 的「取最小」对应。

## 样式栏与调节面板

**样式栏**：六种样式平分一行，不用再横着滑。每项上面一个小样子，下面是名字；小样子跟着参数走——色块是当前的颜色、表情是当前的表情、马克笔是当前的颜色，不点开面板也看得出下一笔是什么样。选中的那一项垫一颗胶囊（Material 3 导航栏的选中指示），名字后面一个小箭头。顺序改成色块、表情、抹除、马赛克、模糊、马克笔：不可还原的排前面，与 README 的样式表一致。

**面板**：点一种样式就换成它，并在样式栏下面弹出它的调节面板；再点当前那一项收起或重新展开。面板右上角有收起按钮，返回键也先收面板（吸管在等取色时先收吸管）。面板顶上一行小字说清楚改的是什么：

- 没有选中框：「之后打码都用这个样式，打好的不变」；
- 选中了手动框：「改的是选中的框，之后打码也用它」。

底下是「恢复默认」（只把这一种样式的参数放回出厂值，别的样式调好的不动）和「应用到全部 N 处」。

面板不盖画布：画布在上面实时变，与用途水印面板同一个思路，但用途水印面板顶替底栏，这个面板夹在样式栏和导出按钮之间，导出不用先收面板。面板最多占屏幕高度的四成（横屏三成），多出来的滚动。安全性说明（模糊、马赛克、马克笔）和抹除的降级说明仍贴在样式栏下面，面板收起时也在。

每种样式能调的：

| 样式 | 能调什么 | 边界 |
|---|---|---|
| 色块 | 颜色：10 个预设（天蓝、黑、灰、白、红、橙、黄、绿、蓝、紫）、自定义、吸管 | 永远不透明 |
| 表情 | 20 个表情；底色：8 个预设（深灰、黑、白、天蓝和四种浅色）、自定义、吸管；排列：单个 / 排满 | 底色永远不透明 |
| 抹除 | 背景太复杂、改用色块时的颜色（与色块的颜色是同一项） | — |
| 马赛克 | 颗粒：细（出厂）、较细、适中、较粗、粗、很粗 | 不能比出厂更细 |
| 模糊 | 强度：轻（出厂）、较轻、适中、较重、重 | 不能比出厂更弱 |
| 马克笔 | 颜色：8 种荧光色、自定义、吸管；浓淡 20%～70%（出厂 60%） | 永远透得过去 |

边界是安全底线，不是审美，读设置、吸管取色、自定义颜色都要过一遍（`MaskOptions.normalized`）：

- 色块、表情底色不透明：底色是盖住内容的那一层，半透明就等于没盖；
- 马克笔到不了 100%：它只做标记（§8），边是手绘抖动的，盖不严，调成不透明就是一块不受控的色块；
- 马赛克只能往粗调：出厂的块已经是 §15.6 实测会泄漏的量级，再细只会更容易被还原；
- 模糊只能往强调：比出厂更弱的模糊连「看上去遮住了」都做不到。

**颜色**：色板排不下就折到第二行，不横着滑——吸管不会藏在屏幕外面。「自定义」那一格是一圈彩虹，点开是色相、饱和度、亮度三条滑条，轨道画的就是拖过去会得到的颜色；当前颜色不在色板上时它是选中的，圈里填着这个颜色。HSV 由滑条自己记着，不从颜色反推：饱和度拖到 0 时颜色成了灰的，色相再也算不回来，反推的话色相滑块会一下跳回红色。

**吸管**：点一下进入取色，画布顶上浮出「点一下图片，取那里的颜色」和「取消」；再点图上任意一处，取那里的颜色。

- 取的是原图的颜色，不是画面上已经打了码的颜色——想让色块和卡片底色融成一片，要的正是底下的颜色；
- 取 3×3 像素逐通道的中位数：只取一个像素，正好点在字的抗锯齿边上或 JPEG 噪点上，取回来的是谁也没想要的颜色；
- 这一下不切换打码、不选中框；点在图外（留白处）不算，接着等；拖手指画框照常画，画完吸管收起；
- 马克笔取色只换颜色，浓淡不变。

**表情排满**：沿长边排满一排，字号仍按短边算，整排居中。截图上要遮的多是长条形的文字行，只在正中放一个表情，两边是一大段空底色，不像样。

**马赛克的颗粒**：块边长 = max(区域短边 / divisor, 12px × max(1, 8 / divisor))。出厂 divisor = 8 时就是原来的 max(短边/8, 12px)。往粗调时下限按同样的比例抬高：截图上一条文字行的短边多半不到 96px，那里起作用的一直是 12px 下限，只放大比例的话，滑条在文字上拖不出任何变化。调得越粗，越多的小框放不下一格、按原来的规矩改用色块（§8），面板上滑条下面写明了这一点。

## 持久化

画笔是编辑器里记住的偏好，和原来的「上次样式」一样：样式仍存在 `last_style`，各样式的参数逐项存（`mask_solid_color`、`mask_pixel_divisor`、`mask_blur_ratio`、`mask_marker_color`、`mask_emoji`、`mask_emoji_background`、`mask_emoji_tiled`），读回来一律 `normalized()`。拖滑条时每帧都会改画笔，落盘去抖 400 ms。不是设置页上的项，「恢复默认设置」不动它。

冷启动时画笔是异步读回来的：识别结果要等它读完再打码，否则第一张图会用出厂的天蓝色块，而不是用户上次调好的样子（读 DataStore 只要几毫秒，识别要一两秒，实际上不用等）。用户抢在读回来之前动了画笔，以用户的为准。

每块码的样子跟着 `MaskPlan` 进 SavedStateHandle，Activity 重建后原样回来；画笔从设置里读。

## 测试

| 层 | 测什么 |
|---|---|
| 单测（模型） | `toggle` 打码时用给的样子、退回圈出时不动；`maskAll` 只给它打码的项换样子；`restyle` / `restyleMasked`；`MaskOptions` 的边界与「恢复默认」只管一种样式；逐块样式穿过 Parcel |
| 单测（渲染） | 表情的底色与排满；马克笔的浓淡；马赛克往粗调时下限跟着抬、出厂档不变；导出逐块按各自的样式画；抹除挨着色块时导出与预览一样读到原图 |
| 单测（ViewModel） | 换样式只管下一次打码；点虚线框用当前样式；选中框跟着面板变、之后的框也是；只选中不改画笔不动；拖滑条一步撤销；应用到全部一步撤销、不碰圈出的；恢复默认；面板开合；画笔活过换图与重开；吸管取原图颜色、不切换打码、点图外不算、马克笔保留浓淡 |
| 单测（设置） | 画笔参数的默认值、往返、越界值收回范围、「恢复默认设置」不动画笔 |
| 单测（Compose，Robolectric） | 六种样式都在、点了报出来；安全与降级说明；面板只在打开时出现、说明随选中变；色板、自定义颜色（读屏调进度与手指拖动都是「拖动中 → 收尾一次」）、吸管开关；表情、底色、排列；抹除的降级色；马赛克、马克笔的滑条；恢复默认、应用到全部的可用状态 |

原先在 androidTest 里的样式栏测试挪进了 Robolectric 单测：放在 androidTest 里 CI 不跑。

## 未验证

- 只在 Robolectric 截图上看过样式栏和各面板的排版（412 × 915 dp），没上真机；小屏（360 dp 宽）、横屏下面板与画布的比例还没看过；
- 吸管在真机上的手感：手指盖住了要取的地方，3×3 中位数在高倍缩放下够不够准；
- 面板展开、收起时画布跟着缩放重新适配，每帧重画所有码，模糊块多时低端机上的帧率。
